# Whistle Block Secure
Whistle Block Secure is a blockchain-based platform designed to empower individuals to report misconduct safely and anonymously. In environments where speaking up can lead to retaliation or suppression, traditional whistleblowing systems often fail to protect the reporter. This platform addresses that challenge by utilizing decentralized technology to guarantee data integrity, eliminate central authority control, and ensure that reports cannot be modified or erased.

At its core, the system combines a secure, user-friendly frontend with smart contracts deployed on the Ethereum blockchain. Reports are hashed and stored immutably on-chain, making them tamper-proof and transparent, while identity-related data is never captured, preserving complete anonymity. For authorized reviewers or investigators, a controlled dashboard enables structured access to submitted reports without compromising the reporter’s identity.

Whether used in corporate settings, government institutions, or activist networks, Whistle Block Secure represents a shift toward more trustworthy, resilient whistleblowing solutions built for the digital age.

## Features
Anonymous Reporting – Whistleblowers can submit reports without revealing their identity.

Blockchain-backed – Reports are securely stored using smart contracts on the Ethereum blockchain.

Web3 Enabled – Seamless interaction between frontend and blockchain via MetaMask.

Modular Architecture – Clean and scalable project structure for easy maintenance and expansion.

Admin Dashboard – Secure interface for authorized personnel to view and act upon reports.

## Usage
Connect your MetaMask wallet.

Submit an anonymous report via the web form.

Reports are hashed and stored on Ethereum.

Authorized reviewers can access and verify reports via the admin panel.

## Architecture
Client: Handles form submission, blockchain interaction, and admin views

Smart Contracts: Store immutable report hashes and metadata on-chain

Server: API for data validation, routing, and secure interactions with smart contracts
